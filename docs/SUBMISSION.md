# 參賽交付說明

## 作品描述

決策群島把《決策智慧》轉成可探索、可串讀、可持續擴充年份的閱讀網站。讀者穿過宇宙螺旋書塔，抵達對應原刊章節的群島。第一次來，可以挑一個自己在意的問題，沿策展路線讀幾篇，再回頭探索其他觀點。

2026 首版提供22篇觀點、全文搜尋、原作者與來源、字級調整、收藏及閱讀足跡。動畫可以略過，文章可以獨立開啟。其他年份尚未假裝收錄，必須經過匯入與來源校對才會出現。

## 製作歷程

使用 Codex 與 GPT Astra、Sol、Luna 子代理協作。先以瀏覽器讀取比賽規則與參考互動，再比較靜態內容出版與前端場景方案。兩者合併成離線資料匯入、靜態文章與原創3D場景。

關鍵指令包含先做2026、保留未來十年匯入、參考可探索島嶼、以宇宙螺旋書塔進場。實作時將內容管線及場景分給不同代理，避免同時修改相同檔案。主代理整合閱讀介面並負責實際操作驗收。

來源PDF為橫式跨頁，PDF檔案頁碼與印刷頁碼不同。匯入器分別保存，並保留各篇PDF供核對。文章摘要與導讀標示為編輯資料，策展路線不冒充作者原話。

## 部署與資安自評

採 GitHub Pages 靜態託管，因網站主要工作是公開閱讀，不需要後端、帳號或資料庫。網站內容隨版本建置，GitHub Actions 僅在部署工作取得 pages 寫入權限，其餘工作只讀儲存庫。正式網址與驗收結果記錄在工作紀錄。

沒有伺服器端上傳入口，沒有執行期 AI API，也不要求讀者登入。收藏與閱讀進度僅使用 localStorage，沒有分析追蹤器或廣告腳本。GitHub 作為託管供應商仍可能有自己的基礎設施存取紀錄。

發布資料只包含比賽允許公開的刊物內容與網站必要圖像。原始工作Excel、InDesign、字型及刊物聯絡資料頁不在公開網站內。作者署名作為刊物出處保留。

前端以文字跳脫處理刊物內容，設定CSP，限制外部來源、物件與表單。外部新分頁連結使用noopener。GitHub Pages不能讓本專案任意設定所有HTTP安全標頭，CSP以meta提供，無法據此宣稱完成公司正式安全核可。

依賴與秘密檢查、資料對帳、手機尺寸模擬、鍵盤、動態偏好及真實網站讀回結果，以最終驗收紀錄為準。正式公司SSC、service tier與Security評估不由本作品自行認定。本作品依活動規則作公開靜態競賽交付，並非宣稱通過企業系統正式上線審批。
