使用者要求更接近首爾星空圖書館，並提供左右弧形書牆、玻璃中庭與金色聖誕樹的照片參考。中央樹仍以書本堆成，新增慢速旋轉。採SOP B+C，來源為Notion即時讀取，沿用poteto-mode Feature流程。

- Blocking first steps. 已讀場景與轉場實作，保留公開閱讀介面及來源內容。
- Independent workstreams. Luna獨占library-scene.ts，負責曲面書牆、木紋、書脊與旋轉樹；Sol獨占entrance.ts及其測試，負責連續鏡頭及時間計算。
- Shared mutable state. 主代理獨占world.ts整合及頁面樣式，兩個實作分支不修改共用場景檔。
- Smallest safe decomposition. 分成空間材質與純動畫兩個模組，保留現有createWorld外部契約。主代理負責桌機、手機、暫停、減少動態及發布讀回。

驗收重點是實際畫面中的弧面尺度、書籍細節與中央樹；正常模式持續慢轉，暫停與背景分頁停止，減少動態不自動旋轉；鏡頭轉場須能完成且仍可直接略過。
