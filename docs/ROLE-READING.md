# 從「跟我有關」開始閱讀

2026-10-24的產品方向優先於早期主題島首屏規格。入口以讀者的生活或工作情境為起點，主題地圖留作自由探索。初次畫面不攤開人物、日誌、時間與關聯工具。

## 閱讀流程

1. 先選「行銷工作」或「日常生活」，再選該類的細分角色。也可以直接自由探索或開文章目錄。
2. 選一個在意的問題。可以略過，取得該情境的第一個起點。
3. 進入與角色相關的生活或工作小任務。每回合選一個具體行動，看到可能影響、代價與書中觀點。
4. 帶著先前決定進入下一回合，或比較、改選、略過。三回合後整理自己的處理方案，尚未回答的部分不計完成。
5. 可選讀三篇來源文章、重做任務或改選情境。閱讀全文沿用原有收藏、已讀、PDF及瀏覽歷史，閱讀器的下一步返回下一輪任務。

最新入口分兩大類。行銷工作含品牌與行銷企劃、內容與創意工作者、媒體與數據洞察工作者、行銷主管與團隊決策者。日常生活含家長／家庭觀察者、人生轉換／退休生活探索者、職場新鮮人、忙碌通勤讀者。這是使用者自行選擇的閱讀情境，不推測身分、不進行政治或個人建議分眾。刊物原文聚焦品牌、人與AI，導讀與關聯明示為本站策展。

## 資料與未來書籍

`journey-types.ts`描述書籍、兩大類、細分角色、問題與三個文章步驟。`reading-journeys.ts`的`JOURNEY_2026`只綁定2026與完全相同的原刊標題。文章標題、作者、摘要與時間一律從當前Edition的canonical articleId取得，不複製成另一份內容。

`buildReadingJourneys(edition, definition?)`會檢查書名、年度、文章引用、角色與問題ID、三篇不同文章及雙語文案。第二與第三步的connection只允許complement、tradeoff、context，表示編輯安排的補充、取捨與背景，不能暗示文章之間已證明必要因果。

年度JSON可加入可選的`journeys`欄位，其形狀為`JourneyDefinition`。每本書填自己的`bookId`（等於Edition.title）、`year`、`notice`、`audiences`與`personas`。每個步驟明確使用`articleId`，或使用該書內的`articleOrder`。匯入新PDF之後，先校對原文，再編排新的角色導讀。未提供導讀的書顯示「尚未編排」與該書真實文章入口，不套用2026推薦。

現有年度PDF匯入流程不會自動生成角色導讀，也不宣稱對未知書籍已完成策展。保留原JSON時可新增`journeys`；重新由匯入器生成年度JSON後需重新加入經審閱的配置。

## 情境資料

每個step可加入mission，欄位見journey-types.ts的JourneyMission。scene與goal描述這輪情況及目標，choices中的label、outcome、tradeoff記錄具體行動、可能結果與代價，takeaway連回該step原文。來源只有step.articleId，不另複製文章。2026由journey-mission-content.ts提供16件任務、各3輪、每輪2個選項。

未來書籍可在自己的journeys.steps中提供mission，也可暫時只提供閱讀導讀。驗證會拒絕重複mission ID、空白雙語文字、重複choice ID或少於2個選項。沒有mission的步驟顯示原文章導讀，不憑空生成任務。選擇只留在目前開啟頁面，與收藏及已讀分開，重載後清除。
