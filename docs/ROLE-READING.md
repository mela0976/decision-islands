# 從「跟我有關」開始閱讀

2026-10-24的產品方向優先於早期主題島首屏規格。入口以讀者的生活或工作情境為起點，主題地圖留作自由探索。初次畫面不攤開人物、日誌、時間與關聯工具。

## 閱讀流程

1. 選生活或工作情境。也可以直接自由探索或開文章目錄。
2. 選一個在意的問題。可以略過，取得該情境的第一個起點。
3. 看到一篇真實文章的摘要、原標題、估計閱讀時間及「為何與你有關」的本站導讀。
4. 自由選第二、第三個角度。每個角度都說明補充、取捨或背景關係，不要求讀完前一篇才解鎖。
5. 回到三個角度一起思考，或改選情境。閱讀全文沿用原有收藏、已讀、PDF及瀏覽歷史。

六種入口為家長／家庭觀察者、人生轉換／退休生活探索者、職場新鮮人、忙碌通勤讀者、品牌／行銷工作者、團隊決策者。這是使用者自行選擇的閱讀情境，不推測身分、不進行政治或個人建議分眾。刊物原文聚焦品牌、人與AI，導讀與關聯明示為本站策展。

## 資料與未來書籍

`journey-types.ts`描述書籍、角色、問題與三個文章步驟。`reading-journeys.ts`的`JOURNEY_2026`只綁定2026與完全相同的原刊標題。文章標題、作者、摘要與時間一律從當前Edition的canonical articleId取得，不複製成另一份內容。

`buildReadingJourneys(edition, definition?)`會檢查書名、年度、文章引用、角色與問題ID、三篇不同文章及雙語文案。第二與第三步的connection只允許complement、tradeoff、context，表示編輯安排的補充、取捨與背景，不能暗示文章之間已證明必要因果。

年度JSON可加入可選的`journeys`欄位，其形狀為`JourneyDefinition`。每本書填自己的`bookId`（等於Edition.title）、`year`、`notice`與`personas`。每個步驟明確使用`articleId`，或使用該書內的`articleOrder`。匯入新PDF之後，先校對原文，再編排新的角色導讀。未提供導讀的書顯示「尚未編排」與該書真實文章入口，不套用2026推薦。

現有年度PDF匯入流程不會自動生成角色導讀，也不宣稱對未知書籍已完成策展。保留原JSON時可新增`journeys`；重新由匯入器生成年度JSON後需重新加入經審閱的配置。

## 驗收

| ID | 可觀察結果 |
| --- | --- |
| J01 | 六角色、每角色兩問題，最多兩次選擇取得首篇摘要與全文入口 |
| J02 | 可跳過問題、直接自由探索，或開原文章目錄 |
| J03 | 每條三篇不同真實文章，推薦理由、關聯性與原摘要分清楚 |
| J04 | 第二、第三角度直接可選，不以已讀解鎖 |
| J05 | 地圖定位正確文章；全文next沿目前路線，第三步不跳回原刊順序 |
| J06 | 關閉全文回到同一路線；收藏、已讀、字級、PDF與歷史保持可用 |
| J07 | 切角色可返回、切書重置，未知書籍與失敗資料不洩漏舊推薦 |
| J08 | 首次不自動開舊說明、人物與日誌，進階工具可展開且用語說明清楚 |
| J09 | 390px、鍵盤、英文、WebGL不可用及減少動態仍能完成閱讀流程 |
| J10 | 聖誕預設、三節慶切換與保存不受新入口影響 |

驗證結果記錄於EXPLORER-RUN.md及實際browser結果檔。角色內容的適用性是來源摘要支持的編輯判斷；尚未進行真實讀者研究，不能宣稱已證明降低認知疲勞或提高理解率。
