# 沉浸式群島開發與驗收紀錄

本紀錄保留完整 Master Prompt 範圍。預覽階段不等同正式完成。

## 目標與入口

以四大群島、22 座文章島、四位原創人物、八類互動和文章關聯航線，呈現《2026 決策智慧》。書塔只負責初次入場。

新入口為 `public/immersive/index.html`。在專案根目錄執行 `python3 -m http.server 4186 --directory public`，開啟 `http://localhost:4186/immersive/`。入口使用原生 ES modules 與固定 Three.js 0.160.0 CDN importmap，不需要執行建置。既有網站的 GitHub Pages 工作流程會原樣複製此目錄。

## 執行分工與依賴

- 基準：`05af8dd`。使用 `immersive-master` 整合工作樹，保留原工作區三項套件更新。
- Luna：`data.js` 與來源、地理、關聯完整性測試。
- Sol：`world.js` 的程序模型、人物、導航與可見互動結果。
- 主代理：入口、閱讀與遊戲控制器、保存、介面、對比及整合驗收。
- 先固定 DATA 引用契約，再平行實作內容與世界。相同檔案只有一位寫入者。
