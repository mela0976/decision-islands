# 群島探索操作說明

[開啟群島](https://mela0976.github.io/decision-islands/)。第一次入場有書本轉場，可按「略過，進入群島」。之後換文章不會重播。

## 開始探索

1. 拖曳海面旋轉視角，滑鼠滾輪或手機雙指縮放。
2. 點人物對話，或按「走進情境」開始這篇文章的小任務。
3. 選擇後觀看人物與道具反應。「查看選擇前」可來回比較；「調整選擇」或「重玩」可重新嘗試。
4. 按「前往推薦島嶼」繼續探索，或直接按「閱讀這篇文章」。遊戲不會阻擋閱讀。

人物台詞與情境是虛構演繹，原刊觀點與來源另有標示。結果不是對真實民意、購買行為或成功率的預測；洞察印記是探索足跡，不是能力分數。

## 找文章與閱讀

「22 座島・目錄」可搜尋文章、作者或關鍵字，也能只看收藏。使用「全景」、上一座與下一座，或切換故事探索／自由閱讀；兩種模式共用進度。

閱讀視窗提供導讀、重點與完整原文。文字可選取，PDF 連結可對照原刊。閱讀後按「標記讀完」，在「我的筆記」留下想法。關閉原文會返回原來情境；Escape 關閉最上層視窗。

## 保存與備份

進度、收藏與筆記保存在這個瀏覽器，不會自動同步到其他裝置。編輯後確認筆記顯示已儲存。無痕模式或清除瀏覽資料可能移除紀錄。

在目錄按「下載閱讀紀錄與筆記」取得 JSON 備份。另一個瀏覽器可用「匯入備份」還原；同篇已有非空筆記時保留目前瀏覽器的筆記，不以備份覆蓋。備份包含你的筆記，請自行妥善保存。

## 手機、動態與離線

「設定」可調整居民數量 10–100、減少動態效果、環境音與三種節慶，預設聖誕節。手機若不順，可減少居民並啟用減少動態。

首次在線載入並完成快取後，可離線探索、讀取已快取的文章與編輯筆記。原刊 PDF 不包含在離線快取中。3D 無法載入或連線中斷時，仍可使用目錄與 2D 閱讀。

若看見更新提示，先等筆記儲存，再按套用更新。非常舊的版本可能沒有更新按鈕：確認筆記已儲存後，關閉這個網站的所有分頁，再重新開啟網址；不必清除瀏覽資料。

## 本機執行與驗收限制

在專案根目錄執行 `python3 -m http.server 4186 --directory public`，開啟 `http://localhost:4186/immersive/`。主應用是原生 ES modules，Three.js 固定為 0.160.0，首次載入需要網路取得 CDN 模組。

目前實測與欠項見 [開發與驗收紀錄](IMMERSIVE-PROGRESS.md)。手機尺寸的瀏覽器測試不等同實體手機驗收；載入速度會隨裝置及網路變化，目前沒有所有裝置兩秒內完成的保證。
